# Documentation

Everything here exists so that someone can understand, build, run, verify or modify the software.

| Folder | Holds | Written when |
| --- | --- | --- |
| [briefs/](briefs/README.md) | One implementation brief per unit of work, with its implementation record | Before the work starts |
| [decisions/](decisions/README.md) | Technical decision records: the decision, its technical rationale and consequences | Before the work that depends on it |
| [architecture/](architecture/README.md) | The current system overview and contributor-facing contracts | As the system changes |
| `model/` | Calculation model specification, assumptions, limitations, rule sources and reference test vectors | With each calculation |
| `guides/` | Self-hosting and user documentation | When there is something to run |

[STATUS.md](STATUS.md) lists what works today and what is being built now. It is generated; do not edit it by hand.

Documents describe what exists.
