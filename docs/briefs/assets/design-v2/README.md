# Design references, version 2

Approved reference screens for the question-led intake and the top of the results (brief 0002-W6). Each PNG is a full-page capture. Unless the file name says otherwise it shows the desktop frame (1280 px) in light; `-phone-light` is 375 px and `-desktop-dark` is the dark theme. Colors and type follow [DESIGN.md](../../../../DESIGN.md).

Figures are output of `horizon-engine-0.4.0` (`horizon intake`) for synthetic answers that describe the example household "Single, 61, still working, plans to retire at 66", taken from the [0002-W4](../../0002-W4-reference-values.json) and [0002-W5](../../0002-W5-reference-values.json) reference values. Questions show that household's answers as a person would type them.
